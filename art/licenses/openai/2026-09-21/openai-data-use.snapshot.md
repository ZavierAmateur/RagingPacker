- 更新日期：2026-03-13
- 检索日期：2026-09-21

## 与本项目相关的内容

- 对 ChatGPT 等个人服务，OpenAI 可能使用用户内容训练模型。
- 个人用户可以通过隐私门户或产品数据控制选择退出；退出后新对话不再用于训练。
- Temporary Chat 不进入历史、不会创建记忆，也不会用于训练。
- 对 ChatGPT Business、Enterprise 和 API 等商业产品，官方说明默认不使用输入或输出训练模型，除非组织明确选择加入数据共享。

## 当前无法确认的事项

- 当前生成会话属于个人账户还是商业工作区。
- 当前账户是否已经关闭“Improve the model for everyone”或通过隐私门户退出。
- 是否使用 Temporary Chat。

因此本项目只记录 `account_data_control=unverified`，不会把训练退出状态写成已经验证。后续提示词继续禁止上传身份证、合同、密钥、客户资料和私人照片。
