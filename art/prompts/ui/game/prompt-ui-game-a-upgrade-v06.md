## 中文信息层级

- 订单商品区增加“订单商品”，明确下方图标是当前订单所需内容。
- 倒计时增加“剩余时间”，避免圆环数字被误解为得分或数量。
- 三项订单要求直接显示“小号箱／气泡膜／易碎”。
- 订单商品不得只显示物品图；在不遮挡数量角标的前提下补充短名称，例如“蓝色手机 ×2／玻璃杯 ×1”。相似商品优先显示可区分的规格词。
- 纸箱正面容量必须显示“箱内 0/4”，不能只显示缺少语义的 `0/4` 和空圆点。
- 底部三个选择入口使用“纸箱 · 小号箱／包装 · 气泡膜／标签 · 易碎”，同时说明类别与当前选项。
- 主操作按钮继续使用“封箱发货”。
- 顶部 HUD 使用短标签或变化时弹字说明“今日目标／金币／完美连单／投诉”；不能长期只靠星星、金币、火焰和表情图标让玩家猜含义。

## 实现约束

- 中文仅用于评审和信息层级确认，不与底板合并为最终资源。
- FairyGUI 实现时文字必须使用独立文本组件，便于适配、换字、状态变化和后续本地化。
- 概念稿中文字使用系统字体叠加；正式运行时沿用项目已约定的字体方案。
- 角色头像继续作为独立组件，可按订单状态切换表情并播放轻量 Tween，不能烘焙进订单卡。
- 多订单仍使用顶部 `01/02/03` 票据队列；当前只展开一单，紧急状态以时间条和颜色提示，不同时展开多张详情卡。
- 图标和文字必须是独立组件；中文是正式信息层，不得只存在于教程截图或 AI 概念图里。
