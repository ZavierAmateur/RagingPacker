# 《暴躁打包员》RagingPacker

> 这个包裹到底能不能发？

使用 Cocos Creator 3.8.8 制作的竖屏可玩原型，目标是验证“看订单 → 选商品 → 选包装/标签 → 封箱判定”的核心乐趣。

## 运行

1. 用 Cocos Creator 3.8.8 打开本目录。
2. 打开 `assets/main.scene`。
3. 点击编辑器顶部的预览按钮。

设计分辨率为 750 × 1334，推荐使用竖屏浏览器预览。

## 已实现

- 20 种商品组成的动态传送带，可点击装箱
- 商品数量与箱子容量管理，可点击箱内商品取出
- 小/中/大三种箱型
- 气泡膜、冰袋、防水袋三种包装
- 易碎、冷藏、防水三种标签
- 30 张订单与倒计时
- 10 个完整关卡与递进难度
- 停电、传送带故障两种随机事件
- 商品、数量、包装、标签和箱型综合判定
- 金币、连击、投诉、订单进度与当日结算
- 10 条正确/错误搞笑评价
- 5 连击传送带减速反馈

## 原型操作

- 点击传送带上的商品：装入纸箱
- 点击箱内商品胶囊：取出一件
- 点击底部选项：选择箱型、包装或标签
- 点击“封箱发货”：结算当前订单

## 代码结构

- `assets/scripts/GameModel.ts`：纯逻辑数据与判定
- `assets/scripts/GameRoot.ts`：Cocos 场景、UI、动画与交互
- `tests/game-model.test.ts`：核心判定单元测试
