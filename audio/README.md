# RagingPacker 音频源资产

本目录保存音频原始素材、编辑工程、正式源文件、授权和生成记录，不直接作为 Cocos 运行目录。

```text
audio/
├─ raw/
├─ references/
├─ edited/
├─ final/
│  ├─ bgm/
│  ├─ ambience/
│  ├─ sfx/
│  └─ voice/
├─ licenses/
├─ provenance/
└─ audio-manifest.csv
```

运行文件使用 `bgm_`、`amb_`、`sfx_`和 `vo_` 短前缀。原始 AI 音频、录音、未核实授权素材和音频工程不得直接进入 `assets/`。
